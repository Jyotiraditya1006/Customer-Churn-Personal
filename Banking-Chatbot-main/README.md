# 🏦 AI Banking Chatbot

A Natural Language Processing (NLP) powered chatbot designed to simulate basic banking interactions. Built with Python and Streamlit for a seamless user experience.

## 🚀 Features
- **Intent Recognition:** Uses Scikit-learn to classify user queries.
- **Banking Operations:** Supports inquiries for balance, fund transfers, and account security.
- **Interactive UI:** A clean, web-based interface built with Streamlit.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **NLP:** NLTK / Scikit-learn
- **Frontend:** Streamlit
- **Data:** JSON-based Intent Dataset
